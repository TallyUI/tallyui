points in its `package.json` `exports` map, in `@tallyui/core` (`.`, `./rxdb`, `./server`),

## Proposed breaking changes (desk first)

1. **Money conversions, one name** (consistency, d and e). Before: `moneyToMajor(money): number`
   (core), `minorToMajor(minor, decimals): string` and `currencyDecimals(code)` (core/server),
   `minorToDecimal(minor, exponent): string` (pos). After: one string-returning
   `minorToMajor(minor, digits)` and one `minorUnitDigits(code)`, both in core and re-exported where
   needed; `currencyDecimals` and `minorToDecimal` removed, and `moneyToMajor` either removed or renamed so
   it is clear that it returns a float.
2. **Remove the 16 deprecated pos internals** (stability). Before: exported from `@tallyui/pos`.
   After: module-private; tests import them from their modules.
3. **`TallyConnector.sync` optional, then gone** (extension, b, d, e). Before: required,
   `@deprecated`. After: optional in a minor bump, which is breaking for readers of `connector.sync`, and removed at the next major;
   the six deprecated `ProductTraits` accessors likewise optional, then removed.
4. **Medusa customer functions, one shape** (naming, b and e). Before: `medusaSearchCustomers(context, …)`
   and `searchMedusaCustomers(baseUrl, headers, …)` (and create, get, update). After:
   `searchMedusaCustomers(context, …)`, as Vendure does; the raw HTTP helpers leave the root entry.
5. **WooCommerce namespaces off the core root** (stability, b and e). Before: `woocommerceTax`,
   `woocommerceCoupons` on `@tallyui/core`. After: moved to the WooCommerce connector.
6. **Remove the deprecated components aliases** `PaymentMethodKind` and `PaymentMethod` at the
   next major (once the consistency fix lands).
