---
title: OrderNoteSheet
description: OrderNoteSheet edits a controlled note live in WCPOS v2's Order details sheet, with a customizable field label.
---

## Import

```tsx
import { OrderNoteSheet } from '@tallyui/components';
```

## Usage

```tsx
import { useState } from 'react';

function NoteEditor() {
  const [note, setNote] = useState('');
  const [open, setOpen] = useState(true);

  return open ? (
    <OrderNoteSheet
      value={note}
      onChangeText={setNote}
      onOpenChange={setOpen}
    />
  ) : null;
}
```

This is WCPOS v2's Order details sheet, opening on the left so the cart's note row stays in view. It writes on every keystroke, and Close calls `onOpenChange(false)`; [Cart](/docs/components/cart) opens it for you when given `noteSheet`.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `string` | required | Current note text |
| `onChangeText` | `(text: string) => void` | required | Called on every edit with the untrimmed text |
| `onOpenChange` | `(open: boolean) => void` | required | Called when the dialog requests an open state change; Close calls it with `false` |
| `label` | `string` | `'Customer note'` | The field's label and accessible name; the placeholder is "Add" plus the label in lower case |
| `taxExempt` | `{ checked: boolean; onCheckedChange: (on: boolean) => void; error?: string \| null }` | --- | Shows the controlled Tax exempt switch and its hint, with an alert when `error` is non-empty; omit to hide the row |
| `taxExemptReason` | `{ required: boolean; text: string; certificateId: string; onChange: (next: { text: string; certificateId: string }) => void; notSent?: boolean; error?: string \| null }` | --- | Controls the staff-only reason and certificate fields; omit to hide them |

## Exemption reason

The fields appear only while the Tax exempt switch is on. Under `required`, the reason is marked required; the certificate number is always optional. The sheet says the reason stays on this till when the host sets `notSent`. Under `optional`, `Cart` sets `notSent` whenever `sale.taxExemptReasonSent` is `false`: the store's `order.create` is below `13`, or the order contains a coupon that prevents it from carrying the reason. Under `required`, `Cart` never sets `notSent`; payment waits until the reason can be sent. Neither field appears on a receipt or the customer display.
