---
title: SplitTender
description: SplitTender is deprecated and renders Tender; split payments are legs on the one tender pane.
---

## Import

```tsx
import { SplitTender } from '@tallyui/components';
```

## Usage

```tsx
import { useSale } from '@tallyui/pos';
import { SplitTender } from '@tallyui/components';

// Inside a component under TaxProvider.
const sale = useSale(settings, { registerId, cashierRef });
<SplitTender sale={sale} />
```

`SplitTender` is deprecated: it renders [Tender](/docs/components/tender) with the same props, so use `Tender`. A sale is split by taking several legs in turn, each in Cash or Card terminal; a leg is cancelled with Cancel payment where its method allows a void.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `sale` | `ReturnType<typeof useSale>` | required | The sale from [useSale](/docs/pos) |
