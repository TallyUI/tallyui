---
title: CartNoteInput
description: CartNoteInput expands from an Add customer note link into a multiline customer note field, with controlled text, a customizable label and placeholder.
---

## Import

```tsx
import { CartNoteInput } from '@tallyui/components';
```

## Usage

```tsx
const [note, setNote] = useState('');
<CartNoteInput value={note} onChangeText={setNote} />
```

Starts as a compact "Add customer note" link. Tapping it expands into a multiline text input. If the value already has content, the input starts expanded. WooCommerce sends the note as `customer_note`, so it shows on the customer's emails and receipts.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `string` | required | Current note text |
| `onChangeText` | `(text: string) => void` | required | Callback when text changes |
| `label` | `string` | `'Customer note'` | The note's name: the link reads "Add" plus the label in lower case, and the input uses it as its placeholder and accessibility label |
| `placeholder` | `string` | the `label` | Placeholder text for the input |
| `className` | `string` | — | Override container styles |
