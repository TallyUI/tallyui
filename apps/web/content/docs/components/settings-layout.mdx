---
title: SettingsLayout
description: Responsive split or collapsible layout for settings navigation and content
---

## Import

```tsx
import { SettingsLayout } from '@tallyui/components';
```

## Usage

```tsx
<SettingsLayout
  headerSlot={<Header />}
  navSlot={<SettingsNav />}
  contentSlot={<SettingsContent />}
/>
```

On wide screens, renders a fixed-width navigation sidebar alongside the main content area. On narrow screens, collapses to a single-pane view with a "Menu" button that toggles the navigation overlay. The layout mode can be forced via the `layout` prop or left to respond automatically based on the breakpoint. On narrow screens a pick closes the menu when `navSlot` is a function that calls `closeNav`, and Done closes it too.

## Closing the menu on a pick

```tsx
<SettingsLayout
  navSlot={({ closeNav }) => (
    <Pressable
      onPress={() => {
        setSection('general');
        closeNav();
      }}
    >
      <Text>General</Text>
    </Pressable>
  )}
  contentSlot={<SettingsContent section={section} />}
/>
```

A plain `ReactNode` navSlot gets no close-on-pick; only Done closes the stacked menu. Pass `navOpen` and `onNavOpenChange` to control the stacked menu yourself: a pick, Menu and Done then report through `onNavOpenChange` and the layout follows `navOpen`. On wide screens a pick does nothing and `navOpen` is ignored.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `navSlot` | `ReactNode \| ((nav) => ReactNode)` | required | Navigation menu content; a function receives `closeNav` to close the stacked menu on a pick |
| `contentSlot` | `ReactNode` | required | Main settings content |
| `headerSlot` | `ReactNode` | --- | Optional top header bar |
| `layout` | `'split' \| 'stacked'` | auto | Force a layout mode instead of using the breakpoint |
| `breakpoint` | `number` | `768` | Width threshold for switching between split and stacked |
| `navOpen` | `boolean` | --- | Controls the stacked menu; absent means uncontrolled |
| `onNavOpenChange` | `(open: boolean) => void` | --- | Called when Menu, Done or a pick opens or closes the stacked menu |
| `className` | `string` | --- | Override container styles |

## Slots

| Slot | Purpose |
|------|---------|
| `navSlot` | Settings navigation menu (left sidebar in split, toggleable overlay in stacked) |
| `contentSlot` | Main settings content area (right side in split, primary view in stacked) |
| `headerSlot` | Top bar rendered above the layout with a bottom border |
