---
title: ChangeDisplay
description: ChangeDisplay shows the change due, a `Money` the caller has already computed, formatted with the store's money format.
---

## Import

```tsx
import { ChangeDisplay } from '@tallyui/components';
```

## Usage

```tsx
<ChangeDisplay change={{ amount: 750, currency: 'USD' }} />
```

Shows a "Change Due" label over the formatted amount. The caller computes the change (a payment flow computes tendered minus total). It shows `—` when the amount cannot be formatted.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `change` | `Money` | required | Change due, already computed by the caller |
| `locale` | `string` | — | Locale used to format the amount |
| `className` | `string` | — | Override container styles |
